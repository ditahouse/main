# dita. Creative House Website

React/Vite website built for Cloudflare Pages.

Cloudflare Pages settings:
- Framework preset: None
- Build command: npm run build
- Build output directory: dist
- Root directory: blank if package.json is at repo root

Includes:
- Crisp SVG logo and favicon
- SEO metadata, Open Graph image, sitemap, robots.txt
- Real URL routing with Cloudflare SPA redirect
- Functional mailto brief form to info@ditahouse.com
